# prontuario-upa

Prontuário ágil para atendimento em UPA/Pronto Atendimento — formulário que gera o registro SOAP (anamnese, exame físico e conduta) automaticamente, pronto para colar no sistema.

Ferramenta: [prontuario-upa.html](prontuario-upa.html) · publicada via GitHub Pages.

Nada é salvo — os dados existem só enquanto a aba estiver aberta.
